# USVocAssigner

A prototype Python program for assigning mouse ultrasonic vocalizations (USVs)
based on amplitude ratio comparison.

## Status

Prototype / Research software under development.

## Features

- Load USV-related data
- Calculate amplitude ratios
- Compare amplitude ratios between candidate animals
- Assign detected vocalizations
- Mark ambiguous vocalizations as unassigned

## Requirements

- Python 3
- NumPy
- Pandas
- SciPy
